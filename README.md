# ポケモンチャンピオンズ対戦データベース CMS完全版

GitHubリポジトリ直下へ、このフォルダの「中身」をすべて上書きアップロードしてください。ZIP自体はアップロードしません。

必要な配置:
- `/index.html` サイト本体
- `/admin/index.html` 育成論編集画面
- `/admin/config.yml`
- `/admin/build-editor.js`
- `/admin/pokemon-data.js`
- `/data/builds.json`

既存の育成論を残す場合は、GitHub上の `/data/builds.json` を削除しないでください。今回のZIPに入っている空の `data/builds.json` では上書きせず、既存ファイルを残してください。

CMS変更点:
- 型名・役割を廃止
- 性格に1.1倍・0.9倍を表示
- 能力ポイントは各0〜32、合計66以下
- ポケモン、特性、持ち物、技を連動プルダウン化
- ポケモンと技のタイプを色付き表示
- メガシンカ後は対応メガストーン固定
- メガシンカ可能な通常形は通常持ち物＋対応メガストーン
- メガシンカ不可はメガストーンを表示しない
