# ポケモンチャンピオンズ 育成論CMS

## 主なファイル
- `/index.html` 公開サイト
- `/admin/index.html` 育成論編集画面
- `/admin/config.yml` Decap CMS設定
- `/admin/build-editor.js` 育成論専用編集UI
- `/data/builds.json` 保存済み育成論データ

## 今回の修正
- 「新しく育成論を作成」と「既に作成したポケモンの育成論一覧」を明確に分離しました。
- 新しい育成論は専用ボタンから配列の末尾へ追加され、既存データを残します。
- 既存育成論のポケモン名は上書き防止のため変更不可にしました。
- 入力途中の新規フォームがある場合、重複して空フォームを追加できないようにしました。

## GitHubへ上書きする際の注意
既にGitHub上の `/data/builds.json` に育成論が保存されている場合、そのファイルは今回のZIP内の空データで上書きしないでください。
今回の修正に必要な中心ファイルは `/admin/build-editor.js` です。ZIP全体を入れ替える場合も、既存の `/data/builds.json` は残してください。
