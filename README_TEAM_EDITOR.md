# 構築編集アップデート

## 追加した機能
- 構築編集を専用の折りたたみ式編集画面に変更
- 6匹それぞれのポケモンを一覧から選択
- 性格を能力補正（1.1倍・0.9倍）付き一覧から選択
- 選択したポケモンが持つ特性だけを表示
- 持ち物を一覧から選択（メガストーンにも対応）
- 選択したポケモンが使用できる技だけを表示
- 能力ポイントは各能力最大32、合計66まで
- サイト側の構築詳細を6匹のコンパクトなカード表示に変更

## GitHubへの反映
ZIP内のファイルを既存リポジトリへ上書きしてください。
既存の構築を残す場合は、現在の data/teams.json を先に退避し、上書き後に戻してください。

古い文字列形式の構築データもポケモン名だけは引き続き表示できます。詳細設定は管理画面で開いて追加してください。
